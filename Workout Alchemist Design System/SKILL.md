If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.
If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Non-negotiables: the chrome is monochrome — near-black, white and greys; emphasis is an inverted fill, never a hue. Exactly three accents exist and they live ONLY on data: gold --pr (personal record), green --gain (improvement), red --loss (decline), plus --danger for destructive actions. Never colour a button, nav item, chrome icon, card fill or chart line. Every coloured element also carries a glyph (★ ▲ ▼ –) and a sign, so it reads without colour — and the glyph follows the NUMBER'S SIGN while the colour follows valence, so a cut shows a green ▼, never an up arrow beside a minus. Two typefaces: Instrument Sans for words, Geist Mono for every number and every uppercase label. Accessibility is a hard constraint: text greys clear WCAG AA 4.5:1, hairlines and non-text greys clear 3:1, nothing renders below 12px or under weight 400, tap targets are 44px minimum, focus is a two-tone `--bg`+`--fg` ring, and no state is signalled by colour alone (links stay underlined, the switch draws a check, active items invert their fill). No shadows, no gradients, no blur — depth is a grey step PLUS a 1px hairline; cards have both. Pill radius on anything tappable, 12px on cards. Controls are deliberately small — 34px fields, 38px buttons, 28px chips — and the 44px tap target comes from the row or grid cell around the control, never from inflating the control itself. Never ship a tall input. Numbers before labels, mono and tabular, decimal comma. Polish copy, second person, one to three word titles, no emoji and no exclamation marks. Phosphor icons (web font, regular weight), never coloured, always with a title — never Lucide/Feather/Tabler, which is what every other tracker uses. Light and dark are equals: one `data-theme` attribute, and `prefers-contrast: more` is honoured. The brand is type — the product name in Instrument Sans 700 uppercase, 0.14em tracked. There is no logo; never draw one.
