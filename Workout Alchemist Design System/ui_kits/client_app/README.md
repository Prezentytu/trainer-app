# Client App UI kit

Mobile app (390×844, dark) — the client's tracker, in the spirit of Gravitus. Screens: **Today** (assigned session) → **Live workout** (set-by-set logging with rest timer) → **Progress** (stats + history). `index.html` is interactive: bottom tabs, start the workout, tap sets done, watch the rest ring.

No source UI was provided; this kit applies the design system's foundations. Composes `components/` primitives.
