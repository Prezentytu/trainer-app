# Trainer Studio UI kit

Desktop web app for trainers (1440×900, dark). Screens: **Clients roster** → **Client detail** → **Plan builder** (interactive click-through in `index.html`: switch tabs, open a client, edit their plan, add exercises from the library, assign → toast).

No source UI was provided; this kit applies the design system's foundations to the product described (trainer creates and assigns plans). Composes `components/` primitives — Button, Input, Select, Tabs, Card, Badge, Tag, StatBlock, Dialog, Toast, Icon, etc.
