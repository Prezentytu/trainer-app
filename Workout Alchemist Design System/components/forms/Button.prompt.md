Gold primary action button; sentence-case label, one primary per view region.

```jsx
<Button icon={<DumbbellIcon/>}>Start workout</Button>
<Button variant="secondary">Save as formula</Button>
<Button variant="ghost" size="sm">Skip</Button>
<Button variant="danger">Delete plan</Button>
```

Variants: primary (gold), secondary (bordered card surface), ghost, danger (copper). Sizes sm/md/lg (32/40/48px). `full` for mobile sticky bars.
