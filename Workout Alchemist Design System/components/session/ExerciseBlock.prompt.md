Groups an exercise's sets: mono caps name, trailing delete, the SetRow stack, then "+ Dodaj serię".

```jsx
<ExerciseBlock name="Lat pulldown" action={<IconButton title="Usuń" size="sm"><Icon name="trash-2" size={14} /></IconButton>} onAddSet={add}>
  <SetRowHeader />
  <SetRow index={1} weight="60" reps="7" />
</ExerciseBlock>
```
