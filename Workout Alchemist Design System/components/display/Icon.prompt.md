Lucide icon by kebab-case name. Requires the Lucide UMD script on the page: `<script src="https://unpkg.com/lucide@latest"></script>`. (Intentional addition — icon wrapper for the Lucide substitution.)

```jsx
<Icon name="dumbbell"/>
<Icon name="timer" size={24} style={{color:"var(--gold-400)"}}/>
```
