Fully rounded button. `solid` is the inverted fill and the only high-contrast element on a screen — one per view.

```jsx
<Button size="lg" full>Rozpocznij trening</Button>
<Button variant="outline" size="sm">Anuluj</Button>
<Button caps size="sm">Finish</Button>
<Button variant="danger" size="sm">Usuń trening</Button>
```

Heights 32 / 44 / 52. Hover = 85% opacity (solid) or a lighter hairline (outline). Press scales 0.97. Focus is a 2px ring in `--fg`.
