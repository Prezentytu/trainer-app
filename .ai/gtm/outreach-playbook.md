# Faza A — 100 dni warm outreach

Cel: 5–10 design partnerów z **≥1 ukończoną sesją klienta** w 14 dniach. Nie signup.

Kanał: **tylko warm**. 20 spersonalizowanych wiadomości dziennie. Content 1×/tydzień jako wsparcie, nie zamiast. Ads: zero.

## Gate

| Sygnał | Próg |
|---|---|
| Pass | ≥5 partnerów z sesją klienta / 14 dni |
| Kill | <3 partnerów z sesją / 14 dni → zmień ofertę lub avatar, nie dodawaj ficzerów |
| Founding | po gate A, od 11. osoby: 490 zł |

## Dzień założyciela

1. 20 wiadomości z listy (`lista-trenerow.csv`) — skrypt [skrypt-aca.md](skrypt-aca.md).
2. Zaznacz status: wysłane / odpowiedź / call / partner / sesja.
3. Jeśli call: white-glove (import + 3 linki na callu).
4. Wieczorem: liczba calli, liczba sesji klientów.

## White-glove (checklista calla)

- [ ] Import 1 planu
- [ ] 3 klienci w panelu
- [ ] 3 linki skopiowane i wysłane (WhatsApp trenera)
- [ ] Trener wie, gdzie jest kolejka „do zrobienia”
- [ ] Termin: „jeden klient odhacza serie w tym tygodniu”
- [ ] Feedback za 7 dni (15 min)

## Lead magnet

Wysyłaj [lead-magnet.md](lead-magnet.md) / stronę `/checklista` **zanim** poprosisz o call. Give:ask 3:1.

Founding 490 zł na `/wdrozenie`. Stripe gdy klucz; inaczej e-mail. FAQ: early access 90 dni, potem próg — bez wiecznego unlimited.
