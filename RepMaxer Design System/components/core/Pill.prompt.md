Filter chip. Active fills solid inverted — this is how the reference screens switch muscle group and exercise.

```jsx
<PillRow>
  <Pill active>Chest</Pill><Pill>Back</Pill><Pill>Legs</Pill>
</PillRow>
<PillRow>
  <Pill text active>Bench Press</Pill><Pill text>Cable Fly</Pill>
</PillRow>
```

Two rows stacked (group, then exercise) is the established pattern. 32px tall, mono 11px caps.
